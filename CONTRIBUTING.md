# Contributing to Application Gateway - Managed HSM Keyless TLS Integration Lab

We welcome contributions to improve this lab! Whether you're fixing bugs, improving documentation, or adding new features, your contributions are valuable.

## How to Contribute

### Reporting Issues
- Use the GitHub issue tracker to report bugs or request features
- Provide detailed information about the issue
- Include steps to reproduce the problem
- Mention the Azure region and resource configuration if relevant

### Submitting Changes
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Test your changes thoroughly
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

### Code Style Guidelines
- Use clear, descriptive variable names
- Include comments for complex logic
- Follow Azure CLI and PowerShell best practices
- Ensure all scripts are compatible with the specified versions

### Documentation Guidelines
- Update documentation for any new features or changes
- Use clear, concise language
- Include code examples where appropriate
- Test all provided commands and scripts

### Testing Requirements
- Test all scripts and configurations in a clean Azure environment
- Verify that the lab steps can be followed successfully
- Include any prerequisites or dependencies

## Development Environment Setup

### Prerequisites
- Azure subscription with appropriate permissions
- Azure CLI or Azure PowerShell
- Git for version control
- Text editor or IDE

### Local Development
1. Clone the repository
2. Set up your Azure environment variables
3. Test changes in a development subscription
4. Validate all documentation steps

## Pull Request Process

1. Ensure your branch is up to date with the main branch
2. Update the README.md if you add new features
3. Add or update tests as appropriate
4. Ensure all checks pass
5. Request review from maintainers
